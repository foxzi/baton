# Справочник схемы сценария

Формат сценария baton v1 (docs/ru/spec.md, раздел 3). Виды шагов, которые раннер пока не исполняет, принимаются как объекты и получают свои поля на том этапе, где они реализуются.

Сгенерирован из JSON Schema, которую печатает `baton schema`, поэтому всегда описывает формат, принимаемый этой сборкой.

### duration

Длительность в формате Go, например 10m, либо число секунд.

Тип: string или number

### size

Число байт, необязательно с суффиксом k, m или g в степенях 1024.

### file

Читает, записывает, дополняет или перечисляет файлы внутри workspace. Задаётся ровно одно из read, write, append и glob.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `read` | [template](#template) | нет | Путь для чтения, относительно workspace. |
| `write` | [template](#template) | нет | Путь для записи, относительно workspace; заменяет содержимое файла. |
| `append` | [template](#template) | нет | Путь для дополнения, относительно workspace; создаётся, если не существует. |
| `glob` | [template](#template) | нет | Шаблон, сопоставляемый с путями относительно workspace. |
| `content` | [template](#template) | нет | Текст, записываемый write и append. |
| `parse` | `text`, `json`, `lines` | нет | Только для read: как содержимое файла становится результатом шага. |
| `max_bytes` | [size](#size) | нет | Только для read: наибольший файл, который принимает шаг, по умолчанию 1MiB; файл больше — ошибка. |
